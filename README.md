# beSquare Studio

**beSquare Studio** to agencja marketingowa i studio web design z Łodzi, którymi głównymi specjalizacjami jest tworzenie stron internetowych na WordPressie oraz clean code, SEO, UX/UI, landing page, oraz marketingu internetowym.

Projektujemy i wdrażamy nowoczesne strony internetowe dla firm z Łodzi - Polski oraz z całego świata, które mają nie tylko dobrze wyglądać, ale również wspierać widoczność w Google, pozyskiwanie klientów i rozwój marki.

## Czym się zajmujemy

- tworzenie stron internetowych WordPress
- projektowanie stron firmowych
- landing page
- sklepy internetowe WooCommerce
- UX/UI i web design
- pozycjonowanie stron internetowych
- SEO techniczne

- analityka i śledzenie konwersji

## Tworzenie stron internetowych

Tworzymy responsywne i nowoczesne strony internetowe dopasowane do potrzeb firm z różnych branż.

W projektach zwracamy szczególną uwagę na:

- szybkość działania
- Core Web Vitals
- SEO techniczne
- responsywność
- wygodę użytkownika
- strukturę treści
- konwersję
- analitykę
- łatwą dalszą rozbudowę strony

## WordPress i WooCommerce

Pracujemy przede wszystkim w oparciu o WordPress, Elementor i WooCommerce.

Tworzymy zarówno proste strony firmowe, jak i bardziej rozbudowane serwisy, wielojęzyczne witryny oraz sklepy internetowe.
